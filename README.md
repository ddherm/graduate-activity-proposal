# 研究生会活动立项申报书 Skill

把当年通知、活动资料和官方 Word 附件交给 AI，完成**规则核对、方案撰写、中文润色、附件填写与格式检查**。

本项目围绕华南理工大学研究生会“揭榜挂帅”竞标制作，内置 **2026—2027 学年规则索引、四份空白附件、格式规格和写作示例**。其他年度使用时，先提供对应年度的通知和附件。

[下载整个项目 ZIP](https://github.com/ddherm/graduate-activity-proposal/archive/refs/heads/main.zip) · [查看空白附件](assets/templates) · [复制提问示例](examples/prompts.md) · [填写活动信息清单](examples/intake.md)

## 从没用过 Skill？先看这里

Skill 是给 AI 的一套工作说明，加上它需要的模板、参考资料和小工具。安装后，你仍然用中文提需求；AI 会按照这套流程做事。它不是独立软件，也不会安装后自动开始申报。关于这种目录结构，可参阅 [OpenAI 技能说明](https://learn.chatgpt.com/docs/build-skills)。

使用本项目需要一个**能够读取和修改本地文件的 AI 工作环境**。以下教程以 Codex 为例。你还需要能打开 `.docx` 的 Word 或兼容软件，检查最终版面。普通网页聊天如果不能访问你的文件，只能协助写文字，不能直接修改你电脑上的附件。

本技能自带 humanizer-zh 润色规则，未单独安装 humanizer-zh 也能使用。它会保持申报书的正式语气，删减空话和重复，不会修改事实、数字和已确认的约束。

## 第一步：安装

在支持技能安装的 Codex 对话中，复制发送下面这段话：

```text
请使用 skill-installer，从 https://github.com/ddherm/graduate-activity-proposal 安装技能。
仓库根目录就是技能目录，安装名称为 graduate-activity-proposal。
如果已安装同名技能，请先比较版本并保留我的个人配置，不要直接覆盖。
```

安装完成后，在下一轮对话中输入 `$graduate-activity-proposal` 调用。如果没有识别到，开启一个新对话再试。

也可以下载上方 ZIP 并解压，把包含 `SKILL.md` 的整个文件夹交给 AI，说明“请读取这个目录中的 SKILL.md，按它处理我的申报材料”。这种方式不要求先完成安装，但每次需要明确提供技能目录。

## 第二步：准备一个活动文件夹

建议建一个专用于本次申报的文件夹，像这样放资料：

```text
我的活动申报/
├── 活动信息.md       ← 用下面的信息清单填写，也可以直接在聊天里说明
├── 资料/
│   ├── 当年通知.pdf
│   ├── 往届活动材料/  ← 可选：总结、真实数据、报道、照片
│   └── 格式参考/      ← 可选：你希望严格参照的 Word 成稿
└── 附件/             ← 本次直接填写和修改的 Word 文件
```

- **当年通知**：从学校发布渠道取得，连同后续补充说明一起提供。公开包保留规则索引，未附含联络信息的通知原 PDF。
- **Word 附件**：已有学校发的当前附件就用当前文件；没有时，可从 [空白附件目录](assets/templates) 复制本项目的 2026 年快照。先核对学校是否更新过模板。
- **活动信息**：至少说明校级还是学院特色、活动名称、牵头学院、联办学院、时间、预算及资金来源。已有资料可以整批交给 AI，无需先自己整理成文书。
- **往届与图片**：有就提供，没有可以写明缺失。AI 会区分往届事实、本次计划和待确认资源。

也可以请 AI 帮你建目录：“请用技能里的 prepare_workspace.py，在我指定的新目录初始化学院特色活动工作区。”初始化工具只创建新目录，不覆盖已有项目。

## 第三步：复制这段话，开始填写

把方括号中的内容换成自己的信息；不知道的填“待定”，希望留空的明确写“留空”。

```text
$graduate-activity-proposal

请帮我申报研究生会活动，并直接填写我指定附件目录中的适用 Word 文件。

活动层级：[学院特色活动 / 校级活动，二选一]
活动名称：[活动全称；校级活动还需填写通知中的项目编号或官方全称]
拟报等级及类别：[学院特色活动填写；未定可先给出建议]
牵头学院：[学院名称]
联办学院及校区：[实际参加的学院，各自所属校区及分工]
活动时间、地点、覆盖校区：[已定安排；未定请标注]
核心内容：[准备为同学做什么，有哪些环节]
总预算及来源：[总额；申请校研会资助；企业/自筹资金；各自确认状态]
负责人及联系方式：[填写或明确留空]
通知文件：[本机文件路径]
附件目录：[本次允许直接修改的目录路径]
往届资料、照片：[路径；没有就写没有]
格式参考：[路径；没有则使用技能内置规格]

先读取通知和现有文件，缺少关键资料时集中问我。
保留真实事实，拟定安排用计划语态，不编造调研结果和合作承诺。
附件4在合适位置放真实往届图片和本次活动架构图；缺少纪实图片时，留出位置并写明应补什么图片。
请完成适用附件的撰写、humanizer-zh润色和版面检查，再写回原文件。
最后告诉我还缺哪些信息、图片或签批，以及当前是否具备提交条件。
```

不确定如何描述活动，可先填写 [活动信息清单](examples/intake.md)。[提问示例](examples/prompts.md) 还提供了完整的学院特色、校级和后续修改用法。

## 会填写哪几个附件？

| 文件 | 用途 | 校级活动 | 学院特色活动 |
|---|---|:---:|:---:|
| 附件1 | 学院参与校级竞标的汇总表，需要学院全部相关项目 | ✓ | 通常不适用 |
| 附件2 | 单项学院特色活动申报表，含不少于500字论证 | 通常不适用 | ✓ |
| 附件3 | 活动竞标申报书，含承办单位和竞标论证 | ✓ | ✓ |
| 附件4 | 活动竞标策划书，含流程、预算、应急、宣传和成果 | ✓ | ✓ |

这一分流依据附件用途；如果秘书部另有明确报送口径，以最新要求为准。四份模板都提供下载，不代表每个活动都要填四份。详细字段见 [附件使用说明](docs/attachments.md)。

**Word 附件并不等于完整竞标包。** 2026—2027 学年规则还要求校级函评 PPT 或学院特色答辩 PPT。只需要 Word 时可以明确限定范围；要求“整套申报材料”时，技能会把 PPT 纳入工作范围，并按当前工具能力完成。签名、盖章和审核意见保留给对应人员办理。

## 文件和排版怎么处理？

**已有项目直接在你指定的附件上修改。** 初次使用先复制空白模板到自己的工作目录，之后所有修订都写回这些文件。AI 会在内部工作区留备份、生成候选并核验，不应反复给你另外一套“最终版”。正式报送时再按通知要求整理名称。

格式优先顺序为：**你最新的明确要求 → 你提供的参考成稿 → 本项目内置格式规格**。字体、字号、段落、表格按各自角色处理，不整篇统一成一种格式。

当前内置的重点约定：

- 附件3、4封面的学院名称、学年、主标题：固定30磅行距，段前、段后各0.5行。
- 附件4目录条目：1.5倍行距。
- 各级标题、正文、表格等完整设置见 [格式基准](references/format-baseline.md)；机器可读记录见 [样式元数据](references/format-baseline.json)。

这些是经实际材料确认的排版约定，不是声称通知明确公布了所有字体参数。空白附件保留原始模板结构，填写时还需应用这些格式规格；下载空表不等于拿到了排好版的成稿。

本仓库不提供字体文件。电脑缺少参考字体时，保留文档中的字体声明，并由你安装有使用权的字体后复核；替代字体预览不能证明最终打印效果一致。

## 图片怎么放？

附件4根据内容安排往届照片、成果截图、本次活动架构图或流程图。纪实图片只使用能够核对活动和年份的真实材料；本次架构图依据拟定方案绘制。

没有合适照片时，可以保留带说明的空位，例如：

> 【待补图：上一届企业专家技术讲座现场。需能体现讲座主题与参与情况；请人工核对活动年份及图注。】

交付说明应列出仍需补图的位置。带待补图、待补负责人等内容的文件属于待完善稿，不能标为可直接提交。详见 [图片规则](references/visual-evidence.md)。

## 我拿到文件后，需要检查什么？

1. 活动名、学院分工、时间、人数和预算是否与实际一致，几个附件的数据是否一致。
2. 待填项和照片是否补齐，拟邀请、拟申请的内容是否准确保留了状态。
3. 用 Word 查看封面、目录页码、每页表格和图片，核实字体与分页。
4. 按当年要求准备签批、PPT、文件命名及报送材料。

如果只想继续改一句话、一组数字或某种格式，直接说明修改范围即可。技能应同步相关附件中的关联数据，保留你已经手动修改的其他内容。

## 常见问题

**必须会写代码、运行命令吗？**

不用。安装和使用都可以把上面的中文请求发给 AI。`scripts/` 是给代理或维护者使用的辅助工具。

**没有分清校级和院级怎么办？**

技能会先问清层级。校级还需要具体项目编号或官方全称；学院特色需要明确等级、内容类别及牵头学院，未定时可先讨论建议。

**能否直接沿用示例人数、预算、调研数据？**

示例只演示写法。真实申报用自己的证据和已确认信息；目标可以拟定，但不能把计划写成已经取得的成绩。

**为什么还要提供通知？**

内置索引对应2026年9月28日通知，不会自动更新。新年度、补充说明和新附件都可能改变要求。缺少当年文件时仍可先写方案，但不能确认已满足全部当年规则。

**为什么只生成了文字，没改 Word？**

先确认 AI 能访问你给的路径并具有文档编辑能力。请明确“直接填写指定目录中的 Word 附件”；如果环境缺少文件权限或渲染能力，应让它报告具体缺项，不把未经排版核验的稿件称为终稿。

**可用于别的学校吗？**

可借鉴撰写、证据和核验方法，但华工的项目编号、名额、时间、附件和格式不能直接套用。请提供目标学校规则并要求重新适配。

## 给维护者

辅助填表工具依赖 Python 3、`python-docx` 和 `lxml`；依赖列表见 [requirements.txt](requirements.txt)。初始化脚本仅使用 Python 标准库。下面命令都在仓库根目录运行，普通使用者可交给 AI 执行。

```sh
python3 -m pip install -r requirements.txt
python3 scripts/prepare_workspace.py --kind college --dest ./local-projects/我的活动
python3 scripts/validate_package.py
```

`--kind school` 准备附件1、3、4，`college` 准备2、3、4，`all` 准备全部四份。目标目录必须尚不存在。定点填写工具的使用方式与限制见 [工具说明](references/docx-helper-guide.md)。

更新规则时先读 [来源与年度更新](references/sources-and-updates.md)，不要只替换学年数字。修改技能后结合 [自检场景](evals/evals.json) 检查实际行为；包校验通过只说明文件、链接和快照完整，不能代替真实申报的事实核查与逐页版面检查。
