# 四个附件怎么用

开始填写前，先取得当年的正式通知和当前版本附件。仓库文件是2026年的空白快照；下载单个Word时，可在GitHub文件页面使用下载按钮，也可以在仓库首页下载整个ZIP。

## 下载与分工

| 附件 | 下载 | 需要准备什么 |
|---|---|---|
| 1：校级竞标汇总表 | [下载附件1](../assets/templates/附件1%20XX学院参与校级活动竞标汇总表.docx) | 本学院全部校级竞标项目、角色、联合单位与联系信息 |
| 2：特色活动申报表 | [下载附件2](../assets/templates/附件2%20活动竞标申报表.docx) | 活动等级、类别、牵头学院、参与学院与不少于500字论证 |
| 3：竞标申报书 | [下载附件3](../assets/templates/附件3%20活动竞标申报书.docx) | 活动基本信息、承办与协办单位、资源优势和竞标论证 |
| 4：竞标策划书 | [下载附件4](../assets/templates/附件4%20活动竞标策划书.docx) | 背景、目标、执行流程、人员、经费、安全、宣传与成果 |

校级通常填写1、3、4；学院特色通常填写2、3、4。若要同时申报多个活动，先说明学院总体项目清单，再为每个活动单独建立附件3、4，避免内容串项。

## 附件1：学院汇总，不是单项简介

只提供当前活动资料，不能得出学院全量竞标数。填写时需要区分牵头和另外参与的项目，并按当年上限核对；缺少全量清单就应将计数状态列为待核实。

## 附件2：特色定位与论证

写清拟申报等级、内容类别、联办学院和服务全校的方式。“全类型名额”与“学术思辨类”等内容类别是不同字段，不混为一谈。论证从真实学生需求、学院资源、具体活动、预期成果展开，不能用大段口号凑字数。

## 附件3：让评委知道谁来办、凭什么办得成

各学院优势按实际材料填写，不用其他学院或往年团队经历填补空缺。竞标论证应达到模板要求的字数。负责人、联系方式必须来自用户；签字、盖章、审核意见留给真人和组织办理。

## 附件4：把方案写到能够执行

沿用官方章节和表格结构，预算与附件2、3一致。特别注意：

- 表7-1：活动流程安排，核对时间、环节、工作内容与责任分工。
- 表8-1：详细预算，核对规格、单价、数量、合计和资金来源。
- 表10-1：预期工作投入与成效，区分人数与人次、目标与实际成果。

图片放在能够支撑对应论述的位置，例如往届基础旁放真实现场图、内容安排旁放本次架构图。没有照片就按用户要求标注待补，不凭空生成历史活动照片。内容填完再更新目录和页码。

更细的字段说明见 [附件字段映射](../references/attachment-map.md)，版面要求见 [格式基准](../references/format-baseline.md)。

## 提交前最后确认

已填写不代表手续齐备。复核待补字段、图注和目录，按最新通知准备PPT、签批和报送命名。2026年度通知与附件旧填表说明存在差异，处理依据见 [来源与年度更新](../references/sources-and-updates.md)。不要只凭旧模板上的文字判断交件时间和签字时点。
