# 可直接复制的提问示例

下面活动和学院代称均为虚构演示，所有数字均为示范计划，不是可挪用的历史成绩。发送前替换路径和事实。预算不代表学校资助标准；联办数量和窗口仍需核对自己的当年通知。

## 1. 学院特色：从资料到附件

```text
$graduate-activity-proposal
请申报学院特色活动“研创共学·跨学科实践工作坊”。
拟报A级全类型名额，内容类别为学术思辨类，不是A级命题活动。
A学院牵头，B、C、D、E学院联办，共5个学院，面向全校三个校区研究生。
拟在本学年开展4次学生共学、2次专家讲座和1次成果展示；目标招募15支团队，每队3—5人，预计45—75名参赛学生。
讲座与公开交流的参加者单独统计，不与参赛学生重复累加为去重人数。
总预算12000元，其中拟申请校研会2000元、拟申请企业支持10000元；企业支持尚未确认，不能写成已到账。
过去只举办过院内共学，具体材料见“[往届目录]”，不能编造其他历史成绩。
负责人及联系方式暂时留空。其他学院优势没资料的先留空。
通知在“[通知路径]”，待填写附件在“[附件工作目录]”。
请原位完成附件2、3、4；使用内置格式规格，附件4放真实照片或明确待补图位置。
缺的关键资料请集中问我，已能写的部分先完成。这次仅制作Word，并列出完整报送还需准备的内容。
```

示例中的“45—75名”只是15支、每队3—5人的容量估算，不是已报名人数。正式写作还应根据真实报名规则、现场容量和师资确认目标。

## 2. 校级：官方项目要明确

```text
$graduate-activity-proposal
我要竞标2026—2027学年校级B4：“权心权益”系列活动之职点迷津。
A学院牵头，B、C、D学院参加，总计4个学院。
A、B学院属于五山校区，C、D学院属于大学城校区；服务覆盖一校三区。
拟于2026年11月开展求职主题讲座，国际校区的具体参与方式请结合资源提出可执行方案。
目前只有拟邀请嘉宾名单，还没有确认参加，不得写成已邀约成功，也不承诺内推或录用。
预算尚未确定，请先给测算建议，不把建议当已批准经费。
本学院其他校级竞标项目在“[项目清单路径]”，请据此核验附件1汇总和数量上限。
通知在“[通知路径]”，附件在“[附件工作目录]”，资源信息在“[资料目录]”。
请直接填写附件1、3、4，按humanizer-zh润色并检查版面。
```

这组五山2＋大学城2是2026年索引中的一种有效组合；不能把两个区间上限相加，也不能把服务覆盖校区数等同于承办学院来源数。

## 3. 已有材料：只改数字和相关表述

```text
$graduate-activity-proposal
继续修改“[附件目录]”中的现有材料：
学生共学改为4次，专家讲座改为2次，参赛团队目标改为15支，每队3—5人。
删除短视频制作与播放量相关计划，保留已确认的其他宣传方式。
请同步核对摘要、正文、日程、预算、人员配置、架构图和成效表中的关联数据。
不要把本次计划场次写成往届实际成绩。保留其他已修改内容，直接写回原文件。
```

如果资金用途发生变化，同时写清“总预算、各来源、每项用途”，避免不同附件各保留一套数字。

## 4. 只调整指定格式

```text
$graduate-activity-proposal
只修改“[附件目录]”的以下格式：
附件3、4封面的学院名称、学年、主标题，固定30磅行距，段前后各0.5行。
附件4目录条目改为1.5倍行距。
其他字体、字号、正文和表格保持当前设置。检查相应封面与目录分页后原位保存。
```

## 5. 图片不齐：先做待补图版本

```text
$graduate-activity-proposal
为附件4补充图片与图示。
往届照片在“[图片目录]”，具体年份和活动见“[图片说明路径]”。
已有图片先核对再使用，本届架构图根据当前方案绘制。
缺失的现场照片留出位置，标注需要哪一届、哪个环节、展示什么内容，并交给我审核添加。
列出最后仍需补图或核对图注的位置，直接修改原附件4。
```

## 6. 新年度：先更新规则再写

```text
$graduate-activity-proposal
我要申报新的学年活动。请优先读取“[新通知路径]”和“[新附件目录]”。
先核对相对于内置2026—2027索引的变化，再根据新规则处理。
活动基本信息见“[信息清单路径]”。不沿用旧年度期限、项目状态和学院名额。
```
