# 四个附件的字段与回填方法

依据2026年活动竞标附件原件确定字段；字体和版式按 [格式基准与原位保存](format-baseline.md) 的对应参考件。读取时按文档标签定位，以下表序仅辅助：附件3第一个表含封面布局，不是申报数据表；合并单元格读取可能重复出现，不能重复填或重复计数。底稿所有重复数据从同一来源写入。

## 附件1：学院参与校级活动竞标汇总

用途：学院级汇总，不是单个活动简介。按本技能的附件用途分流，校级适用，纯特色活动不填虚构校级事项；这不等于通知明示豁免提交，若秘书部要求附不适用表，或用户明确要四份，按主流程单列处理。通知允许牵头2项与另外参与6项分别计算，合计最多8项；B1明确不占竞标数额，C1/C2不参与竞标，D1已完成竞标不得当作当前新竞标。

| 字段 | 填写与核对 |
|---|---|
| 标题学院/学年、研究生会名称 | 全称；2026–2027学年。去掉模板中“方正仿宋GBK”提示文字，使用对应字体属性 |
| 合计、牵头数量、参与数量 | 与学院全部清单一致，去重；牵头与参与角色不可对同一项目重复统计 |
| 牵头活动明细 | 最多2项；有几项填几项，不足行写“无”或留结构清晰的空行，删除示范字样 |
| 参与活动明细 | 最多6项，同上；未知不是“无”，需核实 |
| 学院覆盖校区 | 据真实覆盖勾选；模板默认三个√不能原样留下 |
| 负责人、联系人、各联系方式 | 分别按主席团成员、对应部门负责人实际填写，不复制通知发布方联系方式 |
| 学院团委意见、签名日期、公章区 | 留待本学院指导老师和同级团组织按要求办理，不生成同意意见或假签章 |

## 附件2：学院特色活动申报表

| 字段 | 填写与核对 |
|---|---|
| 标题/活动名称、牵头单位 | 学年、牵头学院、活动全称准确；等级可在论证/名称旁适当说明，不改核心表头 |
| 参与单位 | 逐一填写，可按原注释增行；不把牵头单位重复算参与单位 |
| 覆盖校区 | 据活动真实服务安排选择，具体方案在附件4解释 |
| 牵头负责人/联系方式 | 真实信息，与其他附件一致 |
| 活动策划论证 | **不得少于500字**，完成下述内容，不能把模板提示本身计入字数 |
| 参与院研会意见 | 全体协办研究生会主席团成员需签字确认，保留空间；不代签 |
| 牵头学院团委意见 | 留给审核单位，不代写“同意”或签批时间 |

论证应包括主题意义、主要内容和基本形式、目的效果、重点难点、可利用资源、时间和分工。明确写出七项：①线上宣传渠道数量/内容数量/阅读量；②线下渠道种类/覆盖校区数；③现场人数/物料数量；④学院特色点数量及内容；⑤预算金额；⑥回收物资数量；⑦其他实际有关的预期。正文建议用连贯段落，必要数字用短表；不以七项清单替代论证。

附件1、2的签批时点应单独核对：通知关于中标后签字的明确对象是“申报书”，不能据此认定汇总表/特色申报表的签章也全部免于前期办理。若本次电子报送是否需扫描签批页尚无明确说明，交付中注明待按秘书部口径办理，正文制作继续进行。

## 附件3：活动竞标申报书（两类共用）

保留封面、填表说明、申报承诺和签字栏结构。学年、学院、活动名称、各申报单位、申报日期要覆盖封面与内页；牵头单位放首位并注明。空白装饰表不要误写。

主要数据表（原件第二个表）：

- 项目名称；各申报单位/负责人/联系方式，可按模板说明增行；项目联络人及联系方式。
- 项目预计起迄时间：填具体日期并说明包含筹备还是正式举办期，与附件4一致；举办期须符合项目预定主办时间。
- 经费：经费用途、金额、需资助、备注；金额与附件4表8-1对应，资助申请合计单独复算，不默认等于总额；不涉及的行处理为空行/无并删除示范字样。
- 删除该表明确要求在正式表删除的字体/增行注释行；不是删除真实审批/承诺说明。
- **活动策划论证不少于500字**：覆盖主题意义、内容形式、预期目的效果、重点难点、校内外资源，及与附件2相同的七项工作与成效信息。校级按项目定位展开，特色按学院特色展开。
- 研究生会意见及签名日期：不得代写已通过意见。

模板的“竞标当日交两份申报书”与通知冲突，执行通知第8页的“中标后打印签字”；不要向用户宣称电子申报前必须拿到签章才可写完所有正文。

## 附件4：活动竞标策划书（两类共用）

封面填写项目、主办、承办、牵头和策划日期。模板主办单位为华南理工大学研究生会，按官方框架保留；若本活动主办关系另有确认，按事实处理并核对口径。主办、承办、协办、赞助不能混用。

保留原十章及其子标题：一主题、二目的意义、三可行性（主题/活动/安全）、四创新点和承办优势、五影响力、六内容、七流程（前期/现场/后期）、八预算、九应急及其他、十预期成效。更详细内容放入匹配章节；需要的证据放附录，不重排成通用模板。

### 图片与图示落点

图片不改变十章结构。第三章“活动可行性分析”或第四章“承办方优势分析”可插入核实过的往届工作坊、竞赛、企业参访等照片；第六章“活动内容”可用活动架构图说明模块关系；第七章“活动流程”可用流程图说明时间与交付衔接。每图服务于附近的具体论点，不为凑页数堆图，也不以图片代替三张必填表或500字论证。

图源选择、纪实图注、缺图留白及人工审核按 [图片与活动架构图](visual-evidence.md) 执行。图号和标题按实际章节编排，例如“图6-1 活动培养路径（拟）”；正文引用与图号一致。原模板页眉标识属于应保留的官方元素，不拿活动图片替换。

### 表7-1：活动流程安排表

字段：阶段、工作内容、负责人、完成时间、所属单位。每项关键动作有负责人和时间；跨校区另明确实际执行地点。正式表不能保留“XXX”“X月X日”或“方正仿宋”样例。流程过长可继承对应数据行格式增行并合理跨页；保留参考件表头、列宽与字号，不为压页将内容改成小号字。

### 表8-1：详细预算

字段：序号、名称、规格、数量、单价（元）、总价、备注及合计。统一金额口径，逐行乘积、分类小计和总额各自校验。合并格中的分类小计不是每个子行都重复支出。物资回收、场地管理在本表备注或紧邻说明中有落点，支撑表10-1引用。

### 表10-1：预期工作投入与成效

逐项填写右侧“预期/计划应用”，已有“见表…”应核实内容并可补说明：

| 组别 | 完整指标 |
|---|---|
| A 活动前期宣传 | A1.1校级/院级线上渠道数；A1.2制作内容篇数；A1.3阅读人次；A2.1线下渠道个数；A2.2五山、大学城、广州国际校区分别覆盖情况 |
| B 统筹 | B1时间安排（见表7-1）；B2筹备人数 |
| C 影响 | C1.1预计现场参与人数；C1.2预计现场物料件数；C2.1后续校内影响；C2.2后续校外影响 |
| D 创新 | D1形式创新；D2内容创新 |
| E 环保 | E1勤俭节约；E2满足落实需要；E3物资回收预案；E4场地管理 |

表内部分条目带5分、2分、1分，照原字段保留，不自拟其余分值或据此宣布总分。学院特色点具体数量及内容要在正文/论证明确，不仅勾选“有特色”。

## Word操作与工具边界

1. 记录指定附件原路径及当前散列，原件是最终写入目标。内部备份和候选可在工作区制作，最终须回写原路径。按格式基准分别检查当前原件与对应参考件的段落、表格、合并、样式、页眉页脚/图形。排除macOS `._` 辅助文件，不把它们当DOCX读取。
2. 可运行 `python scripts/docx_helper.py --help` 查看命令（`python`表示通过当前依赖加载器确认的Python运行时，需可用的python-docx）。`inspect`提供实际定位；按实际结果制作patch。具体命令见 [工具用法与验证](docx-helper-guide.md)，教学补丁见 [template-patch.json](../examples/template-patch.json)。所有写入须校验旧文本，定位失配立即重查，不能盲填。
3. 辅助工具不负责新增章节、表格增行、目录/分页、套用外部格式或文档渲染；这些用文档编辑能力完成。简单回填也须先确认目标文字已采用正确的参考格式，不能把原模板红色提示样式带入成稿。新增内容复制对应角色的段落/数据行属性。缺字体时保留参考件原字体名称，替代字体只能辅助预览，并说明字形尚未完全验证。
4. 清除已确认的填表提示文字及示范占位符；保留真实说明和审批区。空段、空行、空单元格可能承担封面定位、图位或签字留白，不批量删除。字体名提示应转为字体设置，不进入成稿正文。封面制表年月见来源参考，不凭空制造官方日期，也不因清除提示而删掉封面定位段落。
5. 在最终排版后更新目录页码，确认三张表编号和引用正确。工具扫描残留后还要复读正文与表格：无XX不代表已填完，所有0也不代表可提交。
6. 检查字体/字号/段落属性与参考件一致，并渲染逐页核对；结构抽取不能代替版式验证。核验后将候选回写适用附件原路径，重新打开确认。未确认项在交付消息中说明；备份、PNG、核验PDF留在工作区，不在原附件目录另建一套成稿。原位回写可使用工具的 `commit`，无需再向用户确认相同编辑意图。

## 文件命名与包结构

以下为正式报送打包规则。用户日常要求填写或修改时，保持指定原文件名与位置；只有用户要求打包/导出时才按下列规则生成报送副本，不以此段覆盖原位填写约定。

通知第7–8页明确规定附件3、4及PPT名称：`【校级活动/学院特色活动】活动全称+申报书`、`…+策划书`、`…+函评/答辩PPT`；这是字段拼接表达，按实际类别选择一项，避免把斜杠写进文件名。

文件夹：`【校级活动或学院特色活动】活动全称+牵头学院研究生会全称+联系人+联系方式`。实际姓名电话已确认才生成正式文件夹名，参考示例不要泄露或虚构手机号。附件1/2未给单独同类重命名规则，可保留附件序号并替换模板中的学院/学年/活动名，不能把建议命名说成强制。

校级单项目包含适用的附件1/3/4及函评PPT；特色单项目包含附件2/3/4及答辩PPT。学院多项目汇总表与单项目的打包归属按秘书部具体要求处理。两类截止均为2026年10月8日21:00前。发送是独立动作，完成文件不等于已提交。
